## 3. 运动曲线

### 3.1 相机缩放
- **保持 + 线性斜坡**：缩放在若干固定档位之间用 **3–5 帧的纯线性**过渡（每帧步长恒定：1.85→1.53 每帧 −0.080；1.53→0.95 每帧 −0.192；0.95→1.70 每帧 +0.187；1.70→0.98 每帧 −0.144），到位后硬停，没有缓动。
- **两处例外**：86–97 帧和 224–240 帧是**指数缓出**（每帧把与终值的差乘以约 0.6–0.75）；186–205 帧是**指数加速**（每帧 ×1.01→×1.19 递增）。
- 硬切：84（2.90）、86、98、104、137、224。

### 3.2 相机平移
三个成分叠加：
1. **恒定漂移**：约 **4.2 世界 px/帧**（与缩放无关：26–35 帧 4.26，58–64 帧 4.13，227–256 帧 3.8–4.0）。胶片前那段是 13.4/帧。
2. **冲量 + 衰减**：在节拍帧上突然加一个位移，然后按 ≈0.6–0.8 的比例逐帧衰减。例：41–50 帧 `+19, +74, +43, +17, +11, +8, +7, +5, +5, +4`；104–111 帧 `+195, +33, +20, +14, +11, +9, +7`。
3. **跳切**：37（+225）、51（+74）、57（+136）、60（+107）、65（+69）、72（+520）、79（−230）、89（−173）、91（+514）、137、144（+112）、151（+266）、165（+405）、177（+240）、199（+110）、202（+640）。

> 复刻做法：相机逐帧烘焙（272 个线性关键帧），不靠 AE 的贝塞尔缓动去猜。

**用标尺刻度审计相机（v9 加入，`tools/ruler_res.py`）**：把每一帧原片里的大刻度逐根定位，换算回世界坐标后和理想网格比对，得到「刻度残差」。
- 残差在同一个镜头里应该是常数。0–56 帧和 72 帧都是 −12.5 px，但 **57–71 帧是 −5.4…−3.5**：57 帧那次 136 px 的跳切在展开光流时多算了一格刻度（7.27 px）。修正后这 15 帧整体右移 7–9 px，图钉、日文行、薄荷块和原片对上了，唱片的轨迹也变成一条平滑曲线。
- **98–103 帧** 的残差是 +11.3（应为 −12.5），差值按 36.33 px 的大刻度周期取模后是 −49：这一段相机少算了 49 px，表现为塔楼组和靶子在复刻里偏右 50 px。修正后 86–97 与 98–103 两段对同一批元素的位置一致。
- 2750–3560 这一带（镜像圆圈、金属体画框、`[5921]`）只在 86–103 帧出现过，原先是按黑场段的坐标摆的，整体补 +59 px；同时在两段都出现的目录树和 `2/00` 标签在 104 帧前加 +58…60 px 的位移。
- 标尺刻度相对画面内容**不是完全刚性的**：各镜头之间相差几个到十几个 px（全景拼接的累计漂移），84–85 帧特写还多偏 8 px。复刻里把每帧的残差作为 hold 关键帧加在标尺图层上（`scripts/ruler_off.py`），刻度与原片逐帧误差 ≤1 px。

### 3.3 节拍网格
大多数事件落在**每 6 帧（0.25 s）一拍、相位 5** 的网格上：5、11、17、23、29、**35、41、47、53、59、65、71**…… 实测：月牙环在 35 / 41 / 47 帧各扫一段；三块薄荷绿在 53 / 59 / 65 帧依次出现；代码圆 71 帧；玫红底 95 帧；黑底结束 137 帧；故障条 257 帧开始。

**通用入场手法**：
1. **剪影占位**：先用纯色（白 → 蓝紫 → 实物，或 玫红 → 实物）显示 1–2 帧再换成真实贴图（电线杆、房子、山丘、云、机械线稿都这样）。
2. **1 帧闪断 / 大小交替**（蓝条、光束）。
3. **径向擦除按拍分段**（环形元素）。
4. **保持关键帧（hold）为主**，真正的缓动只有 2–3 帧的缓出。

## 5. 质感

- **全息渐变**：圆锥渐变（粉 / 淡紫 / 薄荷 / 淡黄 / 水蓝）+ 边缘几圈同心亮环，上面压一层细颗粒。
- **颗粒**：纯色块干净，但渐变和灰色环上有明显噪点（静帧里比视频更重）。
- **1-bit / 抖动**：二维码圆、阈值闪帧、靶子图下半的蓝色二值版、图案拼贴块（棋盘、锯齿、条纹）。
- **半调点**：三连圆其中一个的宝蓝渐隐环是点状的；丝带上方的宝蓝条带有喷点噪声。
- **像素化**：鼠标箭头、ASCII 目录树、小人（4.9 倍放大后是硬边像素）。
- **描边线稿**（查找边缘感）：树、电塔、过山车、扶梯机械——灰色细线，局部有碎点。
- **3D 渲染件**：液态金属体（镜面黑白反射）、粉色光泽管子（蓝色管帽）、白模小房子、线框喇叭。
- **照片**：电线杆（高反差黑白抠图）、夕阳、云（饱和宝蓝天）、扶梯、靶子俯拍。
- **胶片扫描**：黑片基、齿孔、金色粗体边码 + 黄色点阵边码、暗红色片基条。
- **系统 UI 截图**：Windows 崩溃弹窗、资源管理器图标排、AE 关键帧文本、维基式表格。

## 6. 版式系统

1. **一根轴**：所有内容挂在刻度尺上，上下对称展开；年份标签（2025 / 2026 / 2030 / 2050 / 2100）直接贴着刻度尺当「时间坐标」。
2. **上实下镜**：蓝条段把尺子当镜面——上面是黑色细圆、原图靶子、正向文字；下面是**蓝色**细圆、蓝色二值靶子、**倒置**的文字。
3. **括号编号**：`(WELL-3) (SLEEP-2) (CANT-1)`、`(1) (2) (3) (4)`、`(crash) (elevator) (METAL)`、`[cloud1] [記憶] [*]`——所有标注都包在括号里。
4. **圆与弧**：大量 1 px 细圆、同心圆、圆弧文字，和实心色块形成粗细对比。
5. **嵌套框**：胶片段是多层黑框互相套叠、旋转 90°，尺子从框中间穿过去。
6. **色彩**：灰底 + 黑白为主，强调色只有 3 个——玫红、蓝（亮蓝 / 宝蓝两档）、薄荷绿；黄色只出现在胶片边码和文件夹图标。
7. **密度节奏**：疏（开场）→ 密（圆环）→ 极密（蓝条 / 丝带）→ 疏（线稿留白）→ 满（胶片黑框）→ 疏（标题版）。

### AE 侧踩到的坑
1. `ae_project_import_json` 只能追加导入；重建时按 id 删掉上一个 `RB_REPLICA` 文件夹再导入。
2. 工程是 16 bpc：**「阈值」的级别按 0–1 计**。
3. 调整层如果不是合成尺寸，效果里的点参数会被「图层 → 合成」换算一次。
4. 混合模式、调整层开关、塌陷开关不在导入 JSON 里，导入后用 `layer.set_blend_mode` / `layer.set_props` 补（清单在 `ae/project_post.json`）。
5. AE 自带 H.264 模板会让玫红偏暗；最终输出走「无损」AVI → ffmpeg（`scale=in_range=full:out_range=tv:out_color_matrix=bt709`）。

### 仍有差距的地方（如实记录）
- 素材仍是重绘/AI 生成的近似件。绳子、金属体、图标组、小楼、黄昏照片、开场甲板照片、小人，以及 v12 的靶子、舌头卡片、扶梯、教堂、C 段两张线稿、电线杆都已按原片参考重新生成，造型接近但不是逐像素一致；少女和云还是第一批生成件（云的轮廓和原片不同）。小人队列里原片有几个是转身/侧身姿势，这里全部用了正面姿势。
- **珠链**：轨道、相位、大小和高光位置是拟合出来的，但珠体的明暗是程序画的平滑渐变，原片更像一张被色调分离过的铬球渲染（黑白对比更硬、珠子之间有小的黑色水滴形暗斑）；云剪影的形状不同，所以珠链背后的灰色「陆地」边缘对不上。
- **线框喇叭**仍是最大的差距：按 27 个关键姿态读数的双曲面线架，位置和朝向对得上，远景里已经加粗加密，但原片的线束中段有一块很深的扭转暗带、左端是一摞很大的椭圆环，这里只是一个收腰的线束；53→54 帧甩动时的中间形态也没有。
