根目录的旧 Skill 副本保留用于兼容已有链接；后续维护以分类目录中的版本为准。旧 Skill 的参考实现见 [rollback-replica](../projects/rollback-q/rollback-replica/README.md)，使用时还需对应的素材、工具和环境；详见项目说明。

后续添加 Skill 时，可使用 `skills/<skill-name>/SKILL.md` 的结构，并把该 Skill 需要的参考文档或脚本放在同一目录下。使用时可将 Skill 文件及其引用的配套资料一同提供给支持 Skill 的 AI 助手，或按所用工具的说明导入。
