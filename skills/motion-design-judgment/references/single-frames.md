# 只停一帧的画面

回答的问题：一帧的闪、反相、空帧里放什么，放在哪里，多久来一次；它在播放时和暂停时各是什么；用它要付出什么。

「一帧画面」在这里指：进入它和离开它都是硬变化的那一帧。第四轮用 `oneframe.py` 在 25 个视频文件里逐帧找出了约 1700 个，再抽了 60 个连同前后帧看过。下面的类型以看过的为准；全体的数字只是检测的结果，标了「检测」。

编号对应的作品和作者见 [cases.md](cases.md)。每一节里，**看到的**是观察，**可能的原因**是我的解读。

| 61—82 个 | V22（15 秒的短片，82 个）、V25、V11、V03 |
| 30—46 个 | V16、V14、V02、V01、V24、V05、V18、V04 |

- 最少的一档是四条插画歌词类（V07、V08、V13、V17），加上 V20 和 V27。
- 最多的一档是两条作品集（V11、V25）、V03 和一条 15 秒的短片。
- 八成以上落在切点上。闪完回到原画面的（镜头内的）只占约一成三。
- 多数是单独一帧；连续 2—6 帧各一个画面的串也常见（第 4 节）。

**可能的原因**

- 插画要留给观众看的时间，一帧的东西会打断它。图形类的画面本来就在按帧变，一帧的画面是这种节奏里最小的单位。
- 作品集把各片段最密的地方剪在一起，所以最多。

**适用与代价**

- 这张表只说明「这批片子里有多少」，不是该放多少。先看自己的片子属于哪一类主体。
- 检测有误报：高速的连续运动里，如果每帧还在换颜色，也会被算进来（V04 1:07 的隧道）。数字只当量级用。

| 同一个版式换一种底色 | V16 第 3968 帧（2:12.4）紫底换成亮绿底；V00 第 1461 帧（1:00.9）白底的楼群换成黑底；V02 第 1612 帧（0:53.7）蓝底换成白底；V34 第 876 帧（0:36.5）红底的歌词卡换成白底灰字 |
| 黑白二值的版本 | V04 第 661、707 帧（0:22.1、0:23.6）蓝底上的灰色碎片变成黑底白碎片，画面里的全息方块不见了；V00 第 651 帧 |
| 只剩底色，内容拿掉 | V16 0:26.8—0:27.7 黄底的版式之间插一帧蓝色的空底，共 8 次；V18 第 2848、2858 帧（1:35.0、1:35.4）只剩深紫的底；V03 第 3390 帧（1:53.1）浅灰的空帧；V03 第 3372 帧（1:52.5）纯白；V05 第 1251 帧（0:41.7）、V24 第 131 帧、V34 第 750 帧是黑 |
| 只剩文字层或标注层 | V23 第 1054 帧（0:43.9）黑底上只有歌词和几个小标注，前后是明亮的三维画面，歌词的位置没有变；V25 第 977 帧（0:40.7）黑底上只有几条细的参考线和角标；V18 第 3050 帧（1:41.8）黑底上只剩几个小粉点 |
| 整幅过曝 | V01 第 3571、3684 帧（1:59.2、2:02.9）一帧白，带放射状的光 |
| 尺度跳一下 | V03 第 3494 帧（1:56.6）卡片里的照片放大一帧又回来；V03 第 1259 帧（0:42.0）新内容的第一帧是占满的大绿圆，下一帧缩回小圆 |
| 换色相或压暗 | V24 第 395 帧（0:13.2）暖色的画面变绿一帧；V04 第 3554 帧（1:58.6）新画面的第一帧是压暗发绿的版本；V03 第 2459 帧（1:22.1）下一段的黑白花纹先以上一段的蓝色出现一帧 |
| 拖影 | V05 第 1683 帧（0:56.2）；V16 0:55.4 |
| 另一幅画面 | 快切的蒙太奇里连续的一帧镜头（第 4 节） |

- 检测到的黑色空帧约 76 个，白色约 50 个，其余颜色的很少。
- 上表前五行有一个共同点：这一帧和前后的画面共用同一个版式或同一个层，换掉的只是极性、底色或「有没有内容」。

**可能的原因**

- 一帧的时间不够读新的东西。把同一个版式换一种状态，观众不用重新找位置，读到的是「闪了一下」。
- 「只剩底色」和「只剩文字层」是把画面拆成层之后去掉一层。它们顺带说明了这条片子是分层想的：底、内容、标注。
- 黑和白最常见，可能因为它们在任何配色里都成立，也最便宜。这是推测。

**适用与代价**

- 先问这一帧和前后的画面是什么关系：同一个版式的另一种状态，还是另一幅画。前者是一次强调，后者是一次打断。
- 反相和二值要求版式经得起（见 [color-and-texture.md](color-and-texture.md) 第 5 节）。V04 的二值帧里，渐变的全息方块直接不见了：经不起二值的东西被拿掉。
- 「只剩文字层」需要文字层本身成立：位置稳定、在黑底上读得出。

## 3. 放在哪里：镜头内、切点上、切点之前

**看到的**

| 位置 | 样子 | 例子 |
|---|---|---|
| 镜头内 | 闪完回到原来的画面 | V05 的四次反相；V16 的蓝色空底；V04 第 661 帧的二值 |
| 切点上，像前一个镜头 | 旧画面的最后一帧换一种状态，然后切走 | V18 第 1111 帧：圆窗的版式反相一帧，下一帧窗里的内容铺满全屏；V25 第 1686 帧：碎片画面反相一帧再切 |
| 切点上，像后一个镜头 | 新画面的第一帧是一个「还没到位」的版本 | V03 第 1259 帧（放得很大）；V04 第 3554 帧（压暗发绿）；V03 第 2459 帧（用旧颜色） |
| 切点上，两边都不像 | 空帧、拖影、只剩一层 | V18 的深紫空帧；V05 第 1251 帧的黑；V23 第 1054 帧 |
| 切点之前几帧（预闪） | 先闪一帧「下一个状态」，回到原画面，过两三帧再正式换过去 | V00 第 1100 帧反相一帧，回到浅底两帧，第 1103 帧正式换成深底；V24 第 915 帧（0:30.5）闪一帧米色的平底，回到原画面两帧，再切到米色 |

- 检测到的切点上的一帧画面里，像前一个镜头、像后一个镜头、两边都不像的大约是 2 : 2 : 5。

**可能的原因**

- 落在切点上的一帧，是给切点加一个「门槛」：旧画面被标记一下再走，或者新画面先以粗略的样子到一帧。切点因此不只是 A 接 B。
- 预闪让观众在正式换过去之前先见过新状态一次。正式换的时候，它已经不是新的了，读起来更稳。这与「先出剪影再出实物」是同一类安排（[motion-and-transitions.md](motion-and-transitions.md) 第 5 节）。
- 空帧把前后两个画面分开，适合两个画面太像、直接切会读成跳帧的时候。

**适用与代价**

- 三个位置解决的问题不同：镜头内的闪是强调；切点上的是给转场加质感；预闪是预告。先定要解决哪一个。
- 新画面第一帧「放得很大」或「压暗」只在这一帧和下一帧明显是同一幅画时才读得出来，否则它就是一帧杂乱的东西。

## 4. 连成一串

**看到的**

- V16 0:26.8—0:27.7：黄底的镜头里，第 802、806、810、815、819、823、826、830 帧各是一帧蓝色的空底，相隔 4、4、5、4、4、3、4 帧。这首曲子的半拍是 4.28 帧。蓝色的那一帧上只留着左下角的片名块和角标；黄底的内容在蓝帧之间接着往前走。
- V18 1:34.9—1:35.5：方括号里的 3、2、1 倒数。三个数字的画面之间各插一帧只有深紫底色的空帧（第 2848、2858 帧，相隔 10 帧，一拍是 9.35 帧）；每数一下，画面里的粉色图形放大一档。
- V05 0:46.7—0:47.1：四次反相相隔 4、4、5 帧，每次带进一行新内容。
- V04 0:02.6：黑底上的胶囊亮、亮、灭、亮、灭（第 80、82 帧是空的），第 83 帧切到黄绿底，胶囊变成同位置、同形状的窗口。
- V16 片尾第 4043—4056 帧：两个画面逐帧交替，共 13—14 帧。
- 连续几帧各换一种底：V02 0:03.3、V18 0:32.4、V16 2:12 各 4 帧（[motion-and-transitions.md](motion-and-transitions.md) 第 4 节）。
- 快切的蒙太奇：V02 里 3 帧、4 帧一串的各有 8 串、4 串；V03 有 6 帧一串的。

**可能的原因**

- 等间隔的一串闪，读起来是一种节奏型，像一串鼓点。V16 的间隔接近半拍，V18 的接近一拍。
- 倒数、分批加内容这类「一步一步来」的内容，用一帧的空或反相把每一步分开，步子就数得出来。
- V04 的亮灭像是切换之前的一次「蓄力」。这是解读。

**适用与代价**

- 一串闪要有尽头。素材里的串都在一秒左右结束，接着是一个大的变化。
- 间隔不是整数帧时，各次之间会差一帧（4、4、5）。这是按时间算位置再取整的结果，不必强求一致。
- 连续的整屏闪就是频闪，见第 8 节。

## 5. 闪的时候什么不动

**看到的**

- V16 的蓝色空底上，左下角的片名块和四角的小标记还在；2:12.4 的亮绿帧上，版式框架也在。
- V18 第 1111 帧反相时，括号里的词在原位。0:12.3—0:12.5 换了三次底，右上角的引号和正中的小物件没有动。
- V23 第 1054 帧，三维背景没了，歌词、四角小字都在原位。
- V04 第 4322 帧（2:24.2）：满屏的隧道变成一帧粉色的平底，正中的小窗口在同一位置，下一帧换成黑底，小窗口仍在。
- V03 第 1259 帧，黄色的外框和卡片标题不动，变的只是内框里的东西。

**可能的原因**

- 一帧的变化要让人看得出「变了什么」，就得有东西没变。留下来的通常就是跨切点的锚点（[motion-and-transitions.md](motion-and-transitions.md) 第 3 节）。
- 角标和片名块留在空帧上，空帧就不是「没信号」，而是「这个系统的空状态」。

**适用与代价**

- 设计一帧画面时，先定它和前后帧共有的东西，再定它不同的地方。
- 什么都不留的空帧（纯黑、纯白）是最强的打断，适合放在段落之间。

## 6. 和音乐的关系

**看到的**（检测加统计）

- 一帧画面前后 1 帧内有重音的比例，多数作品接近随机水平。高出随机的是 V04（2.8 倍）、V05（1.7 倍）、V23（1.7 倍）、V18（1.5 倍）；V20 是 2.0 倍，但只有 11 个。V00、V08、V27 低于随机。
- 对拍的集中度，显著的只有四条：V08（两拍 0.57、四拍 0.67）、V00（四拍 0.42）、V04（四拍 0.40）、V14（四拍 0.37）。
- 也就是说，一帧画面在这几条里聚在小节的某个位置上，而不是每拍都有。
- 局部看，串的间隔可以贴着拍的细分走：V16 的蓝闪接近半拍，V18 的倒数接近一拍。

**可能的原因**

- 多数一帧画面落在切点上，而切点跟的是两拍或小节（[rhythm-and-sound.md](rhythm-and-sound.md) 第 2 节），所以它们对小节有集中、对重音没有偏好。
- V04、V05 是重音由画面内事件来接的两条，它们的一帧画面本身就是那种事件。

**适用与代价**

- 不要默认「闪要卡重音」。素材里多数没有。先定这一帧是切点的一部分，还是一次独立的强调；前者跟着切点走，后者才去对重音。
- 重音是按频谱估计的，没有听过。

## 7. 播放时和暂停时

**看到的**

- 暂停在 V05 第 1404 帧上，看到的是一张完整的黑底白线版式。暂停在 V23 第 1054 帧上，是一张只有字的黑底版面。暂停在 V16 第 802 帧上，是一张只有角标的蓝色空页。
- 这些帧各只存在 1/30 或 1/24 秒。

**可能的原因**（解读）

- 播放时，一帧画面读不出内容，读到的是亮度或颜色的一次跳动，以及「刚才那里有个东西」。它传递的是时间上的重音，不是信息。
- 暂停时它是一张成立的画。这要求它不是随手反相出来的废帧。素材里看过的这些，停下来都成立。
- 所以一帧画面有两个读者：播放的人得到节奏，逐帧看的人得到另一个版本的版式。

**适用与代价**

- 一帧画面上不放必须被读到的东西。
- 想让它经得起暂停，就按一张完整的版式去检查它。这是额外的工作量；在不会被逐帧看的场合可以省。
- 静帧和成片的落差见 [stills-and-motion.md](stills-and-motion.md)。

## 8. 代价与安全

- **光敏风险。** 通行的无障碍准则以「任意一秒内不超过三次闪烁」为界，大面积、高反差的更要小心。素材里有两处明显超过：V16 0:26.8—0:27.7 的 8 次蓝闪（黄与蓝的亮度约差一倍），和 V16 片尾 13—14 帧的逐帧交替。记下它们是因为素材里有，不是建议照做。
- 降低风险的办法：减小面积（只闪一个窗口）；降低反差（在两个中间调之间换）；拉开间隔；一处只闪一两次。
- **码率。** 整屏突变的帧很吃码率，低码率下这一帧和它后面几帧会出现块状。按交付的规格编码后逐帧看一眼。
- **用多了就不是事件。** 每分钟四五十个的片子里，单独一次闪已经不突出，突出的是成串的和带预闪的。
- **检测不等于看过。** 分类是按相关系数做的，会把补色的底算成反相、把过曝算成二值。引用之前取出前后帧看。

## 9. 在自己的稿子上怎么查

| 想确认的事 | 做法 |
|---|---|
| 有多少一帧画面、各在哪 | `oneframe.py <编号>`：帧号、时间、串长、候选类别、在镜头内还是切点上、是否挨着重音 |
| 每一个到底是什么 | `ofsheet.py <输出图> <每格宽> 2 3 <编号:帧号> …`：每个事件一行，前 2 帧、这一帧、后 3 帧 |
| 闪的时候留下了什么 | 在上面的图里逐行指出不动的东西；指不出来的要有理由 |
| 一秒内闪了几次 | 看 `oneframe.py` 输出里相邻事件的时间差；任意一秒内超过三次的，减面积、降反差或删掉 |
| 这一帧暂停下来成不成立 | 取大图，按一张版式检查 |
| 是不是对上了设想的拍或重音 | `onset_at.py` 把起音强度和帧并排；`seq.py bar` 看在小节里的位置 |
