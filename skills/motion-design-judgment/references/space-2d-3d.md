# 三维与二维

回答的问题：平面的东西和立体的东西怎么放在一起；手绘、实拍、渲染这些来历不同的画面怎么并置。

编号对应的作品见 [cases.md](cases.md)。B 开头的是参考图片。每一节里，**看到的**是观察，**可能的原因**是我的解读。成片里看不出各作品的三维部分用的是什么软件、是真三维还是带透视的图层，这里不做判断。

## 目录

1. 两个方向：把二维摆进空间，或者让三维当主体

## 1. 两个方向

**看到的**

| 方向 | 作品 | 样子 |
|---|---|---|
| 把二维的东西摆进空间 | V02、V04、V16、V18、V20，V10 的多数段落 | 带透视的地面网格和贴在上面的字；由大平面围成的隧道；等轴测的梁和方块；平涂的简单立体。材质是平涂或线性渐变，很少有写实的光照 |
| 三维渲染本身是主体 | V22、V23、V24、V25；平面里的 P07、P08、P30、P37 | 碎片、晶体、玻璃、轨道环、隧道。文字退到边角，二维元素负责标注 |
| 电影式的三维角色动画 | V34 | 以镜头叙事为主，平面设计以整屏歌词卡的方式插进来 |

- V00 和 V10 的玻璃段出现了写实三维。
- 平面作品 P10—P16 也有与 V22—V25 相近的碎片爆裂图形，但那是平面的色块。

**可能的原因**

- 这是「谁是主体」的不同回答。图形和字是主体时，空间是为它们服务的舞台，越简单越好。渲染是主体时，图形和字退成说明。
- 两个方向对制作的要求不同：前者要的是版式和节奏，后者要的是建模、材质和渲染时间。

**适用与代价**

- 先定主体，再定方向。两个都想要，就按段落分开，或者像 V34 那样把平面设计做成独立的卡片插进去。
- 把二维摆进空间时，空间一写实，平面图形就会显得贴不上去（第 2 节）。

## 2. 让三维服从二维的规则

**看到的**

- V20 的立体只有两个明度（亮面和暗面），投影是硬边的。楼梯、方块、杆都是平涂。
- V02、V04、V18 的隧道由几块大平面围成，面上是纯色或线性渐变。逐帧量过的 V04 0:58：面的颜色每帧都在变，是一轮连续的色相，13 帧一轮。
- V16 的地面是带透视的网格，字贴在地面上。
- 这些镜头在原始分辨率下没有运动模糊，即使每帧放大 15% 以上（V02、V04、V18）。V16 只在高速的三维文字带和切点帧上有。

**可能的原因**

- 立体的东西只要用和平面图形同一套颜色、同样硬的边、同样没有柔和的明暗，就和平面图形是一家的。观众读到的是「图形有了纵深」，不是「图形旁边放了一个模型」。
- 不加模糊也是这个规则的一部分：平面图形是硬的，空间里的东西也得是硬的。

**适用与代价**

- 适用于图形和字是主体的片子。
- 放弃写实的光照，也就放弃了材质的丰富。金属、玻璃这类效果在这套规则里做不出来，只能用「铬质感的二维图形」这种画出来的替代（V16、V18、V27）。
- 两个明度的立体在形状复杂时读不出结构。素材里的立体都很简单。

## 3. 让二维明确地叠在三维上面

**看到的**

- V22：三维渲染带运动模糊（光点拉成短线、晶体表面拉糊），叠在上面的坐标读数和白色十字是清晰的。
- V24-4K：最快的几帧同样是渲染带模糊、二维文字清晰。
- V23：歌词和四角字幕跨切点不动，背后的三维画面每帧一换。
- V22 的切点上，白色的二维标记（箭头、十字星）不动，背后的场景在青、红、黑、白之间翻转。
- 平面里的 P07、P08、P30、P37：三维渲染是主体，二维的线网、标签和标题压在上面。
- V05 0:54.7—0:55.0（图片 B06 是其中一帧）：黑底上占满画面的大词带柔和的明暗，像浮雕，边缘是虚的；压在上面的放射线、括号编号和释义小字是清晰的、纯白的。大词是不是三维渲染，成片里判断不了；看得到的是两层在清晰度和明暗上完全不同。

**可能的原因**

- 二维层在各方面都和三维层不一样：不受光照影响，不带模糊，不跟着相机动，颜色是纯白或一个纯色。差别大到观众不会把它当成场景里的东西，只会当成「贴在屏幕上的读数」。
- V05 那一处说明，这种分层不需要真的有三维：只要一层柔、一层硬，硬的那一层就会被读成贴在上面的标注。
- 这样一来，它始终读得出来，又给三维画面加了一层「被观测」的意思。
- 它不动，于是成了锚点（见 [motion-and-transitions.md](motion-and-transitions.md) 第 3 节），背后的渲染可以放心地快切和翻转。

**适用与代价**

- 适用于渲染是主体的片子。
- 二维层要细、要少。它一多、一大，就开始和渲染争主体。
- 最别扭的是中间状态：二维元素带了一点光影或一点模糊，又没有完全匹配。要么完全融进去，要么完全分开。素材里选的是后者。

## 4. 不匹配的两种画面，用标注并置

**看到的**

- V14 0:21—0:40：手绘的角色放在金属质感的三维场景里，没有匹配光影。画面上有白色的细线方框。
- V21：平涂的角色放在实拍里；山形的折线压在真实的山上（1:59）；三个带图标的圆排在实拍的枯草地上，一条细线穿过（3:04）；照片的角上有圆形色样和色值小字、手写的日期（1:40）。
- 窗口也在做同样的事：把插画或照片装进一个有边界的框里（见 [layout-and-type.md](layout-and-type.md) 第 7 节）。

**可能的原因**

- 两种画面不匹配时，再加一层图形把两边都「标」起来，画面就成了一张拼贴或图解。观众读到的是有意的并置，不是没做好的合成。
- V21 的图形层在给实拍做注解：折线重复了山的轮廓，色样取自照片。它让观众用设计的眼光去看实拍。

**适用与代价**

- 适用于没有条件或没有必要做光影匹配的时候：角色是别人画好的、实拍是现成的。
- 标注要和它所标的东西有关系（重复它的轮廓、取它的颜色、指向它的某个部位）。和画面无关的标注只是在盖住问题。

## 5. 空间的几种便宜做法

**看到的**

| 做法 | 出现在 | 说明 |
|---|---|---|
| 隧道 | V02、V04、V18、V16（2:04 由带子围成的同心隧道） | 几块大平面向一个消失点汇聚 |
| 带透视的地面网格 | V16 | 字和标签贴在地面上 |
| 等轴测的梁和方块 | V10、V18；封面 P04 的方块塔 | 没有透视，像图表 |
| 线性渐变填充的平面图形 | V02、V04、V10 | 读起来像圆柱或圆锥 |
| 同一组东西换个角度 | V16 2:00 的同心带子，2:04 正对镜头成了隧道。V00 0:37.4—0:39.6 的一组横杆、谱线和带短横的脊线：先正面看（第 910—912 帧），再转到带透视的角度（第 914—919 帧），再换成玫红底白线的版本（第 922—930 帧） | 一份素材几个镜头 |

- V16 的带子上重复印着曲名和信息文字，像一卷卷胶带。高速时字被拉糊。文字在这里是材质。
- 图片 B14 是一张软件视口的截图，画的是 V00 0:38 那个结构，视角与成片里的几帧都不相同。直接看得到的是：这个结构由平面的线和条组成，摆在空间里，可以从不同的角度看。它是哪个软件、成片的这一段由谁做，图片说明不了。

**可能的原因**

- 隧道和地面网格用最少的建模给出最强的纵深感：只要有向中心汇聚的线就够了。
- 隧道的消失点在画面正中，正好是跨切点的锚点常在的位置。
- 隧道里的连续推进上可以再叠一层按帧走的变化。逐帧确认过的例子只有三处，做法各不相同（见 [motion-and-transitions.md](motion-and-transitions.md) 第 1 节）。
- 把平面的线和条摆进空间，换个角度就是一个新画面，不用新做素材。V00 0:38 在 2 秒里用了三个状态。

**适用与代价**

- 这些做法的共同点是空间很简单。它们是舞台，不是景。
- 隧道用久了会单调。素材里每一段隧道都只有几秒到十几秒，而且面上一直在换东西。

## 6. 实物与翻拍

**看到的**

- V10 第 05 段（1:00—1:14）：画架上夹着一块板，摆在走廊、台阶、草地、湖边。逐帧看，板上的图形在同一个机位下每 2—3 帧变一次，长尾夹、编号和纸面的褶皱都在。这块板子随后缩成一个小方块，出现在第 06 段三维场景的画架上。
- V11 1:12：木桌上的剪纸字。
- V03 和 V05 的片尾：翻拍的显示器和工作台。
- V01、V02：CRT 翻拍和彩条。

**可能的原因**（多为推测）

- 把图形做成实物再拍回来，带进了真实的光、反光和不完美，这是数字合成不容易做像的。
- V10 第 05 段像是把动画逐帧打印出来、逐张夹上去拍的定格。成片支持这个判断，但不能排除后期贴图。
- 它只占一段，和前后的纯数字段落形成对比；紧接着又变成下一段里的道具，把两种媒介接了起来。

**适用与代价**

- 实拍一段的成本很高，适合当作全片的一个转折点，而不是通篇的做法。
- 翻拍屏幕会带进摩尔纹、色偏和反光。这些正是要的效果时才用。

## 7. 在自己的稿子上怎么查

| 想确认的事 | 做法 |
|---|---|
| 立体和平面是不是一家 | 把立体的截图转成黑白，看它的明度档数是不是和平面图形一样少；看边缘是不是一样硬 |
| 叠在渲染上的二维层是否始终读得出 | `vis2.py top` 取最快的几帧，看二维层的边缘是否清晰 |
| 并置的两种画面是否像有意的 | 去掉标注层再看一遍。去掉以后像「没合成好」，说明标注在起作用；去掉以后没区别，说明标注是多余的 |
