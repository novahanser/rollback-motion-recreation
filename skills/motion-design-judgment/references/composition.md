# 单帧构图

回答的问题：一帧里，字、图形、主体和底怎么摆；重心、留白、对齐与错位、尺度、层次各是什么情况；线、点、圆、星、箭头、网格在其中做什么；同一帧在连续播放时读到的是什么。

依据是第四轮挑出的 24 帧（每条片子里版式最完整的一两帧），用 `compose.py` 量了像素的分布，再逐帧看过。量到的只是「像素偏在哪里」，哪个是主体、哪个是字，是看出来的。

编号对应的作品见 [cases.md](cases.md)。每一节里，**看到的**是观察，**可能的原因**是我的解读。

## 1. 量到的：重心、留白、左右上下

**看到的**

| V23 0:08.3 歌词 | 50%，48% | 51:49 | 58:42 | 64% |
| V02 0:33.5 章节卡 | 48%，48% | 55:45 | 55:45 | 70% |
| V03 0:21.5 章节卡 | 49%，48% | 53:47 | 52:48 | 72% |
| V18 0:21.3 | 50%，53% | 51:49 | 44:56 | 6% |
| V05 0:55.0 大词与标注 | 48%，47% | 53:47 | 55:45 | 17% |
| V00 0:27.2 粉底全景 | 26%，44% | 88:12 | 58:42 | 75% |

| V20 0:06.6 制作信息卡 | 66%，50% | 20:80 | 49:51 | 32% |
| V05 0:47.3 线稿整版 | 41%，48% | 63:37 | 52:48 | 36% |

- 量了 24 帧，表里列出其中 19 帧。重心离画面中心横向不超过 3% 的有 14 帧。其中有完全对称的（V05 0:21、V24、V34），也有左右内容不同但分量相当的（V23、V02）。
- 明显偏到一侧的有 9 帧，其中 3 帧来自 V00 的 0:22—0:29。
- 留白从 6% 到 98% 都有。最空的是 V26 的片头页，最满的是 V18 0:21。

**可能的原因**

- 这些片子切得快，观众每次只有零点几秒找到「看哪里」。重心在正中或接近正中，眼睛不用动。
- 偏置的画面多出现在有相机运动的段落（V00）和有插画的片子（V08、V13、V17）。前者的画面是长卷的一截，后者要给插画让位。

**适用与代价**

- 这张表描述的是这 24 帧，不是「重心应当居中」的规则。它能回答的是：自己的画面偏不偏、空不空，和设想的一样不一样。
- `compose.py` 把黑边、色块也算作分量。有宽银幕黑边的画面（V34）留白的读数不准；V20 那种半屏色块的画面，重心落在了图案一侧而不是字的一侧。

## 2. 居中与对称：把变化交给时间

**看到的**

- V05 0:21.0：左右镜像。正中是一条发光的竖轴；三个大词放在左上、右上和底部正中，成三角；小标签成对出现在轴的两侧；沿弧线排的两行小字跟着中间光晕的弧度走。
- V24 0:18.5：片名只有画面高度的 6%，放在正中；两侧是对称的大图形，像拉开的幕布。
- V34 0:32.4：一个字压在竖直中线上，左右边缘各有一列极小的竖排标签。
- V26 0:01：一行手写的片名和几行小字，在一张空页的正中。
- V08 1:36.5：两个大字沿中线上下排；左右各一个小方块，一黑一白，在同一高度；左上角的蝴蝶翅膀和几条斜线打破对称。
- V16 0:04：环形的窗居中，左右各一个黑色的爆炸形，片名印在一条倾斜约 15° 的带子上横过环。

**可能的原因**

- 对称的画面一眼读完，不占时间。镜头短的时候，这是最省的排法。
- 对称本身是静的。素材里用三种办法给它加上动势：一条斜的带子（V16）；一件打破对称的东西（V08 的翅膀）；或者让变化发生在时间上——同一个对称的版式上换词、换底、闪（V05、V34）。
- 很小的字放在一个大的对称构图的正中，同样是第一位。它靠的是位置和周围的空，不是大小。

**适用与代价**

- 适用于切得快、需要一眼读完的地方，以及标题、制作信息这类「宣布」性质的画面。
- 全片都对称会闷。素材里对称的画面和偏置的画面是交替出现的。
- 正中的位置只有一个。它通常已经给了贯穿物或锚点；标题要放正中，就得让它自己当锚点。

## 3. 偏到一侧：空的那一边在做什么

**看到的**

- V00 0:27.2（图片 B13 的同一画面）：内容挤在左边一半多，右边三分之一是空的玫红底。刻度尺横贯正中。两帧之后相机推近。
- V00 0:28.8：蓝色大圆占了左中，光束从左下斜到右上，在偏右的地方交汇。
- V00 0:22.4：标题压在上半幅，下半幅几乎只有一个很淡的人物。
- V17 0:28：角色和浅蓝的色块在左和中，歌词放在右侧的空处，高度在角色腰部以下，从不压脸。
- V13 1:13.5：插画的幼苗在中间偏右，两行歌词在左下，贴近下三分线。
- V20 0:06.6：左半屏是色块和两行字，右半屏是图案，一个白色的角色正压在接缝上。
- V05 0:47.3：四行内容从左四分之一排到右缘，唯一的蓝色块在左侧。

**可能的原因**

- 空的那一边有三种用处：留给插画或主体（V13、V17）；留给接下来要进来的东西或相机要去的方向（V00，这是从前后帧看到的）；或者单纯当作喘息。
- 偏置的画面里常有一样东西把两边连起来：V00 的刻度尺横贯到空的一侧，V20 的角色骑在接缝上，V17 的一条灰色粗曲线从角色身侧绕向右下、歌词所在的那一边。
- 上重下轻的标题卡（V00、V08），重的部分正好是要读的部分。

**适用与代价**

- 偏置之前想好空的那一边是给谁的。说不出来的空，观众会读成没排完。
- 偏置的画面需要一点时间才读得到轻的那一边。V17 的歌词要读，那个镜头是慢的。
- 跨越两边的那件东西很要紧。没有它，画面会分成两张。

## 4. 中心留空，内容贴边

**看到的**

- V03 0:21.5 的章节卡：一圈蓝色的边框，标题在上沿（被切掉一半），一个小标签在左下，角上有小方块图案，正中只有几件很小的线稿。画面正中九分之一的区域里只有 1% 的分量。
- V23 0:08.3：歌词在水平中线偏左；右端一个四角星在同一高度；片名在左上，制作信息在右上，状态条在右下，一行小码在左下。四个角各有一件东西，中间大片是暗的三维画面。
- V02 0:33.5：标题在左上，日期在左下，小字在右侧，中间一带是几件散开的粗黑图形。

**可能的原因**

- 把字放到边和角，中间就留给了会动的东西：V03 的内框里每个镜头换一次内容，V23 的中间是三维画面。字不动，中间换，这正是「不动的框，高频的内容」在单帧上的样子（[motion-and-transitions.md](motion-and-transitions.md) 第 8 节）。
- 贴边的字像页眉页脚，给画面一种文档或界面的口吻。

**适用与代价**

- 适用于中间有一样高频变化的内容要保护的版式。
- 贴边的字离画面边缘太近，在有安全框要求的平台或被裁成别的画幅时会丢。
- 中间既空又不动时，画面就散了。素材里中间总有东西在变。

## 5. 层次：几层，靠什么分开

**看到的**

| 画面 | 从后到前 | 靠什么分开 |
|---|---|---|
| V18 0:21.3 | 颗粒的灰底；只露局部的巨大深灰字母；带斜纹的白色胶囊形；括号里的小词和正中的白色星芒 | 尺度（巨大、中、小）和明度（深、白） |
| V05 0:55.0 | 黑底；柔和的窄体巨字；清晰的白色放射线和虚线椭圆；带框的编号和等宽小字 | 清晰度（虚、实）和尺度 |
| V00 0:22.4 | 很淡的灰色人物；超大的衬线标题；压在标题上的粉色圆环；四角的大字；极小的字和细线框 | 明度（淡、黑）、唯一的颜色、尺度 |
| V21 3:38.5 | 纸面；散放的照片；横贯的黑色大字；压在字上的一张照片；边缘的刻度 | 遮挡 |
| V10 0:33.0 | 黑底；深灰的宽体曲名；黑白棋盘格的星形；绿色警示牌和白色竖线 | 反差（低、高）和唯一的颜色 |
| V23 0:08.3 | 暗的三维画面；歌词；带叉的小方框和细线 | 明度和清晰度 |

- 多数画面是三到四层。
- 分层用的手段不止一种，而且同一幅画面里通常只用一两种：尺度、明度或反差、清晰度、唯一的颜色、遮挡。
- 最大的东西常常在最后面（V18 的巨字、V05 的巨字、V10 的曲名、V00 的人物）。

**可能的原因**

- 层与层之间差得越多，快速播放时越不会粘在一起。尺度差一个量级、一层虚一层实，都是不需要仔细看就能分开的差别。
- 把最大的东西压暗、虚化、放到最后，它就成了空间。画面因此有了纵深，而前面的小东西仍然读得清。
- 颜色在这些画面里很少用来分层，更多用来指出一件东西。

**适用与代价**

- 排版之前先数层：底、氛围、主体、标注。每两层之间定一种分开的办法。
- 只靠明度分层，反相之后层次会反过来或消失。要做反相闪的版式，至少再用一种不随明暗变的办法（尺度、清晰度）。
- 层越多，每层要越简单。V18 0:21 有四层、留白只有 6%，它成立是因为每层只有一种形状。

## 6. 对齐与错位

**看到的**

- **对齐到一条线**：V00 的物件都挂在横贯的刻度尺上；V13 的词坐在谱线上；V05 0:47 的内容挂在四组细线上；V21 3:38 的三个大字压在水平中线上；V23 的歌词和右端的四角星在同一高度。
- **对齐到一个块**：V14 的片名和四行制作信息左对齐，成一个块；V20 的两行制作信息左对齐，贴着色块的左缘。
- **成对放在两侧**：V05 0:21 的小标签；V08 的黑白两个方块；V16 0:04 的两个爆炸形；图片 B01 的括号字、B10 的圆环组。
- **有意的错位**：V16 的片名带子倾斜；V18 0:13.5 地面上的两个词一横一斜；V07 的歌词整体右倾、基线上抬；V02 0:33.5 中间的几件粗黑图形各转了不同的角度；V08 大字旁边的小字压在右下角而不是居中。
- **松散的格子**：V10 0:16.5 的过场卡，各项文字大致落在三分线的交点附近，一条细斜线把左上的括号标签引到中间的名字。

**可能的原因**

- 一条看得见的线（刻度尺、谱线、中线）让散的东西有了共同的基准，逐个弹出来也不乱。
- 成对放在两侧的东西标出了画面的宽度和中线，作用像括号。
- 错位是在一个整齐的底子上才读得出来的。素材里错位的东西旁边总有一样很正的东西：倾斜的带子配正的环，转了角度的图形配左对齐的标题。

**适用与代价**

- 先立一条基准（线、块的边、中线），再决定谁守它、谁破它。破的只能是少数。
- 全都对齐，画面是静的、像表格；全都错开，画面是乱的。素材里多是「多数对齐，一两件错开」。
- 斜排的字可读性差，适合短词。

## 7. 线、点、圆、星、箭头：各自的工作

这些东西很容易被当作装饰。下表先写它在画面里的位置和动作，再写它在做的事。后一栏是解读。

| 元素 | 看到的 | 它在做的事 |
|---|---|---|
| 横贯的线 | V00 的刻度尺；V13 的谱线；V05 0:47 的四组细线（它们不是画出来的：第 1390、1391 帧整组出现在两种位置，第 1392 帧落定） | 基准和轨道。先于内容到场，内容挂上去 |
| 引线和斜线 | V10 0:16.5 的细斜线；V08 从小方块引出的细线；V17 从角色身侧绕向右下的灰色曲线 | 把两件东西连成一句话，给视线一条路 |
| 放射线 | V05 0:55 从一点向四周放射的白线 | 给很满的画面一个看得见的中心；也给了纵深 |
| 细线圆和弧 | V02 0:33.5 的大弧；V00 0:27 的十几个细线圆；V08 0:10 的圆和切线 | 不占分量地划出范围；把散的小件圈成一组 |
| 一排小圆点 | V02 0:31 章节卡上最先出现的东西，逐个加到一排 | 计数和节拍。它们先到，像在打拍子 |
| 大的实心圆 | V02 0:31.6 先后出现又消失的两个大黑点；V00 0:28 的蓝色大圆 | 事件（一下重音），或者一块底 |
| 四角星 | V16 1:40.4：出现即最大，头一帧带光晕，三帧里每帧换一个角度，再用四帧缩到消失。V23 画面右端的小四角星 | 一次冲击的记号（来得快、退得稍慢）；或者一个压住版面的小标点 |
| 圆环 | V16 1:40.5：黄色的环用约 7 帧向光盘收拢 | 把视线收回主体 |
| 箭头 | V02 0:32.0：一个巨大的蓝色箭头从右向左扫过章节卡。V16 0:27 的一排尖括号 | 方向；大到占半屏时就是一次擦除 |
| 带叉的小方框 | V23 歌词周围 | 占位和标点：像没有载入的图，或者一个选中的点 |
| 方括号和圆括号 | V05 的括号小标；V10 的括号标签；V18 括号里的小词和数字 | 把一个词标成条目、旁注或计数 |
| 引号 | V18 两个上角的巨型引号，整段不动 | 框。把中间的一切标成「引用的话」 |
| 爆炸形 | V16 0:04 左右两个黑色的锯齿形 | 书挡。夹住中间，也带进了漫画式的口吻 |
| 刻度和十字 | V05 0:55 左侧带刻度的竖线和十字；V21 上下边缘的刻度 | 把画面标成被测量的东西 |
| 粗黑的横条 | V10 0:36.5 横过画面的一根黑色圆头粗条 | 一条重的轴，压住流动的底 |

- 这些元素在动的时候各有习惯：线和框先到并且不动；点和星是弹出的；环和弧有收拢、扫过这类带过程的动作；箭头是扫的。
- 素材里它们几乎都是单色的细线或纯色的面，和文字用同一两种颜色。

**适用与代价**

- 每放一件几何元素，说得出上表右栏里的哪一项。说不出来的先拿掉。
- 同一项工作不需要两样东西。有了刻度尺就不再需要一条基线。
- 这些形状本身谁用都一样。让它属于这条片子的，是它连着什么、指着什么、在什么时候出现。

## 8. 三种方格：透明底纹、黑白图案、大方格

**看到的**

| 样子 | 出现在 | 它是什么 |
|---|---|---|
| 白配约 80% 亮度的浅灰，格子很细（画面高度的 0.7%—2%） | V00、V02、V03、V05、V11、V16（详见 [color-and-texture.md](color-and-texture.md) 第 9 节） | 图像软件里「透明」的样子。多出现在一样东西被拿掉的时刻 |
| 纯黑配纯白，格子很细（约 0.7%） | V10 0:33.0：填在一个四角内凹的星形里，星形打断了后面的曲名；V10 0:41：贴在一条扭转的带子上。V27 1:03 标题卡左右边栏里的小方格条 | 一种高反差的图案，像旗子或测试图。它是一块面的填充或一条带子的花纹 |
| 大方格（约占画面高度的 12%），灰配粉彩 | V20 0:07.9：整幅的底 | 一块地面或一张格子纸 |

- 第四轮之前只找了第一种。检测脚本找的是「两种浅灰相间」，纯黑白的那种不在它的范围里。
- 三种都是方格，读法不同：第一种在说「这里是空的」；第二种是花纹；第三种是场地。

**可能的原因**

- 区别在两种颜色的反差和格子的大小。浅灰对白的细格看上去像「没有东西」；黑对白的细格是最响的纹理；大到能数清的方格读成地面。这是解读。

**适用与代价**

- 说一块方格是「透明底纹」之前，先看它的两种颜色。黑白的不是。
- 黑白细格在低码率下闪得厉害，面积要小。V10 把它限制在一个星形和一条带子里。
- 来历的问题同样只对第一种存在（见 [color-and-texture.md](color-and-texture.md) 第 9 节）。

## 9. 视线怎么走

这一节全部是解读：视线没有被测量过，下面是根据画面里的大小、反差、颜色和线的方向推的。

- **V10 0:16.5 过场卡**：左上括号里的小标 → 沿细斜线 → 中间的信息文字 → 下方最大的曲名。斜线把阅读顺序画了出来；最大的字是终点，不是起点。
- **V17 0:28**：角色的脸（唯一的细节和颜色）→ 顺着身体向下 → 沿灰色曲线向右 → 歌词。
- **V00 0:28.8**：蓝色大圆（面积）→ 光束交汇处（反差和汇聚的线）→ 顺着玫红的带子甩向左下。
- **V05 0:21.0**：正中的光轴 → 左上、右上、底部三个大词。三角形让眼睛绕一圈回到中间。
- **V23 0:08.3**：歌词的首字母（最大、唯一的衬线字）→ 读完这个词 → 沿带叉方框排成的斜线 → 右端的四角星。
- **V02 0:31—0:32 的搭建过程**：视线是被时间带着走的——先是中间的小圆点，再是左下的日期，再是右下，最后才是左上的标题。静帧上最大的标题，在时间上是倒数第二批到的。

**由此得出的做法**

- 画面里要有一个明确的起点：唯一的颜色、最高的反差、或者所有线汇聚的地方。
- 想让观众按某个顺序读，有三种办法：用线把顺序画出来；用大小排出来；用进场的先后排出来。素材里三种都有，后一种最可靠。
- 推出来的视线路径要拿给没看过稿子的人验证。

## 10. 单帧与播放

**看到的**

- 这一份里的 24 帧，是每条片子里版式最完整的时刻。它们在成片里大多只停零点几秒到一两秒；有几帧更短（[stills-and-motion.md](stills-and-motion.md) 第 1 节）。
- V02 的章节卡：静帧上是「标题在左上、内容散开」的一页；播放时是约 0.9 秒的搭建，标题到场时小圆点已经排好了。
- V18 0:12.4：静帧上是「粉底上一个白色的大词」；播放时先是一个粉色的圆，约 10 帧后才成为词。
- V05 0:47.3：静帧上是四行密密的线稿；播放时是四次反相，一行一行加上去。
- V16 0:27：静帧上是黄底的密版；播放时每隔三帧闪一下蓝色的空底。

**可能的原因**

- 单帧上的层级是空间的：谁大、谁亮、谁在中间。播放时还多了一种时间的层级：谁先到、谁停得久、谁在闪。两种可以一致，也可以相反（V02 的标题）。
- 观众在播放时得到的构图，是这一帧和它前后几帧叠起来的印象。闪过的反相、刚到的东西，比一直在的东西更抢。

**适用与代价**

- 排完一帧之后，再排它的时间：每样东西第几帧到、停多久。然后按正常速度看，确认最先被注意到的，是不是想让它当第一位的那一样。
- 只看静帧定稿，会低估后到的东西、高估一直在的东西。

## 11. 在自己的稿子上怎么查

| 想确认的事 | 做法 |
|---|---|
| 重心在哪、空不空、偏不偏 | `compose.py <输出图> <列数> <每格宽> <编号:帧> …`：打印重心、留白、左右上下的比例，并在图上画出三分线、中线和重心 |
| 第一眼落在哪 | 把画面缩到很小，或者只看 0.1—0.3 秒；再对照上面的数 |
| 有几层、每两层靠什么分开 | 逐层列出来。再把画面转成灰度、反相各看一次，看层次还在不在 |
| 对齐的基准是什么 | 在画面上画出那条线或那个块的边；指出哪几件守着它、哪几件破了它 |
| 每件几何元素的工作 | 对照第 7 节的表逐个问 |
| 方格是哪一种 | 量两种颜色和格子的大小 |
| 播放时的顺序和静帧的层级是否一致 | 步长为 1 的条带，记下每样东西到场的帧；和静帧上的大小次序对一下 |
