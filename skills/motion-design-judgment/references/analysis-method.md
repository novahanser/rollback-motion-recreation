# 分析方法：怎么拆一条参考片，怎么量自己的稿子

回答的问题：拿到一段视频，按什么顺序看、量什么、哪些结论可以下、哪里容易看错。

这套方法在 25 个视频文件上用过四轮。第二轮复核第一轮，第三轮复核第二轮并加入了 14 张静态图片与成片的对照，第四轮补看字体、单帧画面、构图和元素到位的方式。历次复核查出的、由方法造成的错误都写在第 5 节。

## 1. 准备

- 需要 `ffmpeg`、`ffprobe`，以及带 `numpy`、`Pillow`、`opencv-python` 的 Python。
- `ffmpeg` 不在系统路径里时，把环境变量 `FFMPEG_DIR` 指到它所在的目录。
- 中间结果默认写到当前目录下的 `motion_work/`，可以用环境变量 `MOTION_WORK` 改。
- 处理下载来的文件时，Python 加 `-I` 运行，脚本和素材分开放。
- 脚本只读视频，不修改素材。

```bash
python -I scripts/scan_all.py <视频路径> <编号>
```

这一条命令会做逐帧扫描、音频扫描和摘要。这批素材的 25 个文件（含 4K）全部扫一遍约三分钟。

## 2. 顺序

先看全貌，再量，再逐帧核对。每一步都可能推翻上一步的印象。

1. **基本参数**：分辨率、帧率、帧数、码率、色彩标记。帧率要看内容的帧率，不只看容器（见第 5 节的重复帧）。
2. **全片扫描**：`scan_all.py`。得到切点和闪帧的列表、镜头长度分布、每 5 秒的指标表、速度候选、调色板。
3. **通览**：`vis.py sheet` 每 1—3 秒一张缩略图拼成一张图，`vis.py colorbar` 画色彩时间线。在这一步划分段落。
4. **定速度**：看 `report.py` 给的候选，用 `acf.py` 核对候选之间的倍数关系（自相关容易落在真实速度的 1/2、2/3、3/2、2 倍上）。片中或标题里写着速度时，和测量对一下。速度可能变化时用 `tempo_track.py` 分段看。
5. **声画关系**：`audit.py <编号> <bpm>`。读法见 [rhythm-and-sound.md](rhythm-and-sound.md) 第 10 节。
6. **看版式**：挑十几到四十个时间点，用 `vis.py frame` 或 `grid` 取大图。记录层级、字号、颜色、质感、画框。
7. **看切点**：`vis2.py cuts` 每个切点一行四帧。记下每个切点上什么没变、什么变了；同时确认检测到的是不是真的换镜头。
8. **看运动**：在入场和转场处用 `seq.py d` 逐帧打印帧间差，用 `vis.py strip` 把步长设成 1 取条带；对连续的镜头用 `motion.py` 解出逐帧的缩放、旋转、平移。
9. **看进场、停留、退场**：挑几样要紧的东西，用步长为 1 的条带各记四件事——怎么来、完整地停了几帧、停的时候在做什么、怎么走。小元素用 `local_events.py` 找它出现和消失的帧；颜色的变化用 `domcolor_seq.py`；要对音乐时用 `onset_at.py`。
10. **看最快的帧**：`vis2.py top` 取镜头内部运动量最大的几帧的原始分辨率裁切，判断有没有运动模糊。
11. **量字号**：`typesize.py`，只用在底色干净的版式上。
12. **有静帧时对一下**：手里有海报、截图或作者发的预览图，用 `still_match.py` 找它在成片里的位置，记下缩放、覆盖范围和这个画面在成片里停了几帧。读法见 [stills-and-motion.md](stills-and-motion.md) 第 7 节。
13. **清点一帧画面**：`oneframe.py` 列出只停一帧的画面，`ofsheet.py` 把要紧的几个连同前后帧排出来看。记下每一个是什么、在镜头内还是切点上、什么没有动。读法见 [single-frames.md](single-frames.md)。
14. **看字和构图**：挑版式最完整的几帧，`compose.py` 量重心和留白，`typemetrics.py` 量要紧的几块字。记外形、粗细、宽窄、字距、行距和对字做的处理；字体的名称不写，除非有制作信息或发布说明可查。
15. **量到位的方式**：对要紧的几样东西，先出步长为 1 的条带看清它是什么，再用 `elemtrack.py` 取逐帧的位置或大小。只写位置序列的形状，不写关键帧参数。
16. **写笔记**，按第 6、7、8 节的写法。看完一条就写，不要攒着。

量自己的稿子时，从第 2 步开始走同样的流程，然后和设想对照。

## 3. 脚本一览

都在 `scripts/` 里。`scan_all.py`、`scan_video.py`、`scan_audio.py`、`palette.py`、`cmp_color.py` 直接读视频；其余的读工作目录里的中间结果，所以要先扫描。

| 脚本 | 作用 | 用法 |
|---|---|---|
| `scan_all.py` | 依次跑逐帧扫描、音频扫描、摘要；给了速度再跑 `audit.py` | `scan_all.py <视频> <编号> [bpm]` |
| `scan_video.py` | 每帧的帧间差、亮度、饱和度、黑白占比、边缘密度；每秒一张缩略图；每秒的色彩直方图 | `scan_video.py <视频> <工作目录> <编号>` |
| `scan_audio.py` | 起音包络、速度候选、分段的响度和高低频能量 | `scan_audio.py <视频> <工作目录> <编号>` |
| `report.py` | 文字摘要：切点和闪帧、镜头长度分布、保持帧统计、速度候选、每 5 秒的指标表、调色板。写出事件表 | `report.py <编号>` |
| `acf.py` | 起音包络的自相关峰值，核对速度候选的倍数关系 | `acf.py <编号> [起始秒 结束秒]` |
| `tempo_track.py` | 分段估计速度 | `tempo_track.py <编号> [窗长 步长 下限 上限]` |
| `audit.py` | 声画关系的五项测量（见第 4 节） | `audit.py <编号> <bpm>` |
| `audit_table.py` | 把多条视频的测量汇总成一张表 | `audit_table.py <输出.csv>` |
| `accents.py` | 列出落在重音上的画面内事件 | `accents.py <编号>` |
| `seq.py` | 逐帧核对：`d` 帧间差序列，`bar` 切点在一个周期里的位置，`hold` 每张画面停几帧，`mod` 事件帧号取余 | 见文件开头 |
| `motion.py` | 一段连续画面每帧的缩放、旋转、平移 | `motion.py <编号> <起始帧> <结束帧>` |
| `vis.py` | 出图：`sheet` 通览、`grid` 关键帧拼图、`strip` 逐帧条带、`frame` 单帧或局部、`colorbar` 色彩时间线 | 见文件开头 |
| `vis2.py` | `cuts`、`cutsat` 切点前后四帧；`top` 最快帧的原始分辨率裁切 | 见文件开头 |
| `typesize.py` | 一帧里各行文字的字高，占画面高度的百分比 | `typesize.py <编号> <帧号或秒> [标注图]` |
| `palette.py` | 直接从视频量强调色：高彩度像素的主色、各自的面积和出现的帧段。不需要先扫描 | `palette.py <视频> [最小彩度] [输出个数]` |
| `cmp_color.py` | 两段对齐的视频在高彩度像素上的逐帧颜色差。不需要先扫描 | `cmp_color.py <参考> <起始秒> <被比> <帧数>` |
| `compare_clips.py` | 参考片段和复刻的逐帧对照：亮度、帧间差、黑白彩面积的相关，大事件的对齐，细节密度和彩色面积的分段对比 | `compare_clips.py <参考编号> <被比编号> [参考起始帧] [分段数]` |
| `still_match.py` | 把一张静态图与某个时间点前后的帧逐帧配准：最接近的帧、缩放、平移、图片覆盖的范围、颜色差；输出「帧、对齐后的图片、两者之差」的对照图 | `still_match.py <图片> <编号> <秒> [前后帧数] [输出前缀]` |
| `local_events.py` | 逐帧找画面里局部的变化（一个字、一个小图形的出现或替换），报告位置和大小。只适合构图不动、元素逐个进出的镜头；相机在动时整帧都在变，它就没有意义了 | `local_events.py <编号> <起始帧> <结束帧> [宽度] [阈值] [裁切]` |
| `domcolor_seq.py` | 逐帧打印面积最大的两种颜色。用来分清「颜色隔几帧跳一次」和「颜色每帧都在变」 | `domcolor_seq.py <编号> <起始帧> <结束帧> [每行帧数]` |
| `onset_at.py` | 逐帧打印起音强度，与帧间差并排。用来看某一处变化落没落在起音上 | `onset_at.py <编号> <起始帧> <结束帧> [每行帧数]` |
| `find_checker.py` | 在一条视频里找两种灰相间的细方格（透明底纹样的棋盘格） | `find_checker.py <编号> [步长] [阈值]` |
| `chk_phase.py` | 量一个区域里棋盘格的格子大小和逐帧相位，判断它固定在屏幕上还是跟着别的东西走 | `chk_phase.py <编号> <起始帧> <结束帧> <x0> <y0> <x1> <y1> [步长]` |

| `oneframe.py` | 找出只停一帧的画面（进入和离开都是硬变化），按它和前后帧的关系粗分类：纯色帧、反相、二值版本、同版式换底换色、另一幅画面；标出在镜头内还是切点上、是否挨着重音。分类只是候选 | `oneframe.py <编号> [输出.csv] [-q]` |
| `ofsheet.py` | 把若干个一帧画面连同前后帧排成对照图，每个事件一行 | `ofsheet.py <输出图> <每格宽> <前几帧> <后几帧> <编号:帧号[:说明]> …` |
| `typemetrics.py` | 粗略量一块字：字高、笔画粗细÷字高、粗细反差、字形宽÷字高、字距÷字高、行距÷字高。底色要干净；字体名称量不出来 | `typemetrics.py <编号> <帧或秒> <x0,y0,x1,y1> [latin\|cjk] [dark\|light] [标注图]` |
| `compose.py` | 量一帧的构图：与底色的差（分量）的重心、细节的重心、留白、左右与上下的比例、中心带的占比；输出带三分线、中线和重心标记的拼图 | `compose.py <输出图> <列数> <每格宽> <编号:位置> …` |
| `elemtrack.py` | 逐帧跟踪一个元素在窗口里的包围盒、质心和面积；列出离终点的距离和相邻两帧剩余距离之比 | `elemtrack.py <编号> <起始帧> <结束帧> <x0,y0,x1,y1> <dark\|light\|#RRGGBB\|diff> [最小面积] [条带图]` |
| `mgrid.py` | 把不同视频的帧（可各自裁切）拼成一张对照图 | `mgrid.py <输出图> <列数> <每格宽> <编号:位置[:裁切]> …` |

位置参数里，帧号写成 `f1234`，秒数直接写数字。第三轮的六个脚本和 `elemtrack.py` 的帧号直接写数字。

## 4. 各项指标的定义

- **硬切**：帧间平均差是邻近帧中位数的 2.5 倍以上，且色彩直方图变化不小于 0.30 或变化的像素不小于 45%。
- **单帧闪**：某帧与前后都差别大，而它的后一帧与前一帧相近。
- **画面内事件**：帧间差出现局部峰值，但没有被判成硬切。
- **运动帧**：帧间平均差不小于约 1 个灰阶。
- **高彩度**：RGB 最大最小值之差不小于 85。
- **相位集中度 R**：把事件的时间按某个周期折成相位，取平均向量的长度。0 是与这个周期无关，1 是全部落在同一相位。显著性按 exp(−N·R²) 估计，N 是事件数。它不需要知道拍的起点，但要求速度恒定。
- **重音**：起音包络（频谱变化的强度）里最高的 4% 的帧，并且是局部的峰值。
- **提升倍数**：事件前后 1 帧内有重音的比例，除以把事件随机放置时的比例。同时给 z 值，大于 2 才算显著。
- **运动量与高频能量的相关**：每 5 秒窗口的平均帧间差，与同一窗口 4 kHz 以上的能量，算相关系数。
- **段落交界命中**：音频的响度和高低频能量在前后各 4 秒的均值差出现峰值的地方，算一个段落交界，最多取 8 个；看它前后 1.5 秒内有没有一次大的色彩直方图变化（全片最大的 14 次）。随机水平按这 14 次的密度估计。
- **步进的突出度**：帧间差序列的平均频谱在 2、2.5、3、4、5、6 帧周期上的值，除以频谱的中位数。大于 2 算突出。
- **整体运动**：相邻两帧做特征匹配，拟合缩放、旋转、平移。内点少于 25 个的帧不可信。
- **字高**：二值化后把连通域串成行，取行内连通域高度的 90 分位。

## 5. 实际出过的错

这些都是在复核里查出来的，每一条都改掉过一个结论。

| 错在哪里 | 发生了什么 | 现在的做法 |
|---|---|---|
| 抽样会造出节奏 | 用每 3 帧取一帧的条带看，三处变化都被读成「每 3 帧一步」。逐帧核对后，一处是 3、5、3、2 帧不等，一处是 2 帧、3 帧交替，一处是每帧一步 | 判断步长只用逐帧的数据：`seq.py d`，或步长为 1 的条带 |
| 缩略图判断不了模糊 | 颜色通道错位的彩边，在 390 像素宽的条带上被看成运动模糊 | 用 `vis2.py top` 看原始分辨率，看边缘有没有沿运动方向的拖尾 |
| 检测器把换底色算成切点 | 同一构图连续几帧换底色或反相，被记成几次硬切和单帧闪。各条的硬切数因此偏高 | 用 `vis2.py cuts` 抽查切点；引用硬切数时说明它偏高 |
| 检测器分不开很近的切点 | 间隔小于 3 帧的切点分不开，于是「3 帧的镜头最多」有一部分是检测下限造成的 | 最短镜头长度的结论要回到逐帧序列里确认 |
| 用「镜头长度约等于几拍」推断声画关系 | 两条片子被写成「一拍一个镜头」。相位检验后，一条没有任何锁定，另一条锁在八拍上 | 用 `audit.py` 的相位集中度和重音重合率 |
| 相信画面里的文字 | 片中的速度标签在一处写 210，另一处写 200，音频全程是 210。另一条片子画面里写着每秒更新 10 次的表达式，实测周期却是 6 帧和 4 帧 | 画面里的数字和代码是设计元素。要用就和测量对一下 |
| 抽成 JPG 再量颜色 | 饱和色的红、绿通道偏了约 18 和 25 级，据此做的复刻整体偏暗 | 量颜色时让 ffmpeg 直接输出 RGB，或者存 PNG。这里的脚本都是这样读帧的 |
| 没有先确认文件是什么 | 文件名带着原作者和曲名的一个视频被当成原片，其实是复刻的第 1 版 | 比较之前，先把它和已知的原片逐帧对一遍（平均灰度差应当只有一两级） |
| 容器帧率不等于内容帧率 | 30 fps 的文件里装着 24 fps 的内容，每 5 帧重复 1 帧。重复帧像是作者做的停顿 | `report.py` 的 `logdiff_autocorr` 在某个滞后上接近 1，说明有固定周期的重复帧。逐帧分析前先剔除 |
| 把饱和度当成稳定的量 | 近黑的像素上，饱和度的数值不稳定，两段视频在黑场段出现了假的差距 | 比较彩色的多少用高彩度像素的面积，不用平均饱和度 |
| 通览会漏短镜头 | 每 2—3 秒一张的通览，在每秒数切的片子里漏掉了大部分镜头 | 快切的段落按切点列表逐个取帧 |
| 在缩小的对照图上判断差在哪里 | 比较参考和复刻的同一帧时，在 390 像素宽的图上把一片黑色墨点看成了「红色小球」，把笔画粗细的差别看成了颜色的差别。放大并量过之后，两者的蓝其实只差十级左右 | 逐项对照用大图（`vis.py frame` 加裁切）；颜色的差别用数值说话 |
| 色表只取了几个代表色 | 参考片段里有深、亮两种宝蓝，色表只记了亮的一种，复刻就把大面积的天空也做亮了 | 用 `palette.py` 对整段按簇统计，连同面积和出现的帧段一起记 |
| 抽样不只造出节奏，也造出时长 | 第二轮已经知道隔帧取样会造出节奏，但只改了当时碰到的三处；用同样的条带得出的其他数字没有回头查。第三轮把技能里引用的 20 条时长说法逐帧重量，13 条要改或撤回。例如「面的颜色每 2 帧换一种」实际是每帧都在变的连续色相；「每 9—10 帧换一次形」实际相隔 82 帧；「字先黑 3 帧」实际是 1 帧 | 发现一种方法会出错时，把用这种方法得出的所有结论都重查一遍。带帧数的说法只用逐帧的数据，并标上依据等级（第 7 节） |
| 长得像不等于同一帧 | 四张图片与一段视频有同样的图形、同样的字、同样的颜色，特征配准却配不上：它们是同一批元素的不同画面。另一张图片与成片的某一段构图相同，缩放却落在那一段的序列之外：成片里没有这一帧 | 说「是同一帧」之前先配准（`still_match.py`），看缩放、覆盖范围和差图。配不上的写「同一批元素」，不写「截图」 |
| 并排图上的色差来自抽帧方式 | 素材附带的核查并排图上，视频一侧的粉和蓝都偏品红、偏暗，看上去像是图片与成片颜色不同。把视频帧按 BT.709 直接读成 RGB 再比，两者只差 1—3 级 | 比较颜色之前，确认两边是用同一种方式读出来的。别人做的并排图不能直接当依据 |
| 把检测器的输出当成结论 | 找棋盘格的脚本在一条片子里报出了一段细密的抖动网点，在另两条里各报出一帧别的高频图案 | 检测器只负责找候选。每一处都取大图看过再记 |
| 从条带上「看出」了滑动 | 一个大词被几根移动的竖条挡着。在逐帧条带上，它露出的部分一帧比一帧靠左，被记成「4 帧从右侧滑入」。第四轮逐帧量它的质心：前三帧几乎不动，第四帧一步跳了 358 像素。是分步跳，动的是挡在前面的东西 | 有遮挡物在动时，不凭眼睛判断被挡的东西怎么动。用 `elemtrack.py` 量质心，或者找一段没有遮挡的帧 |
| 把相近的样子叫成同一个名字 | 「对上焦」被用来说两件事：一块图从粗马赛克变清楚（分辨率在升高），和一组大字由稀疏的小点变成实心。两者都不是焦点的变化。「纯黑的一帧」放大看是深紫色的底色 | 给一个变化起名之前，取原始分辨率的帧看它变的到底是什么；颜色用数值说 |
| 检测脚本的范围窄于问题 | 找棋盘格的脚本只找两种浅灰相间的细格。纯黑白的细格（一条片子里填在星形和带子上）不在它的范围里，于是上一轮没有记到 | 记下每个检测脚本找的到底是什么。「没检测到」只对它找的那一种成立 |
| 跟踪窗口里混进了别的东西 | 按亮度取像素去跟一个白色的星和一个黑色的大字，窗口里还有白线、标签和纹理，质心每帧跳一百多像素，面积忽大忽小 | `elemtrack.py` 的读数要对着条带看。窗口收不干净时，只描述看到的，不报数 |

另外几条一直成立的限制：

- 重音是按频谱变化估计的，不是听出来的。
- 画面内事件只检测得到面积够大的变化。一个小图标出现检测不到。
- R 在切点少、段落多变的片子里天然偏低，不能当作声画配合好坏的评价。
- 平台转码之后，颗粒、细线、高饱和色都和母版不一样。细小的彩色文字会同时丢掉清晰度和颜色。
- 静帧说明不了运动。一张图在成片里怎么来、停多久、怎么走，只能回到成片里逐帧看（见 [stills-and-motion.md](stills-and-motion.md) 第 2 节）。
- 整帧的特征配准量到的是画面整体的缩放和平移。画面里各层运动不一致时，它给的是面积最大那一层的运动。
- `oneframe.py` 的分类按相关系数做：补色的底会被算成反相，过曝会被算成二值，高速运动加逐帧换色会被算成一串一帧画面。类别的计数只当量级。
- `compose.py` 量的是像素与底色的差。它不知道哪个是主体；黑边和大色块也算分量。视线没有被测量过，任何视线路径都是推的。
- `typemetrics.py` 只适合底色干净、没有东西压着的字。它量不出字体的名称，也分不清「细体」和「被压缩糊掉的常规体」；字高不到 20 像素时粗细偏大。
- 位置序列说明不了关键帧。同一串位置可以由减速曲线、按帧计算的衰减或逐帧摆的关键帧得到。

## 6. 记录的写法：观察、推测、待验证

每一句话属于三类之一，写的时候就分开。

| 类别 | 是什么 | 例子 |
|---|---|---|
| 观察 | 在成片里直接看到或量到的。带编号、时间码或帧号，带测量的方式 | 「0:48 的裁切窗口每 3 帧换一个位置，间隔是 3、3、3、4 帧（逐帧打印帧间差）」 |
| 推测 | 关于为什么这样做、怎么做出来的。明确标出是推测 | 「连续镜头里叠着一层每 3 帧更新一次的东西，可能是颗粒或纹理层」 |
| 待验证 | 这次没有查清的 | 「片中的速度标签为什么由 210 变成 200」 |

几条纪律：

- 软件、插件、工程结构、作者意图，一律是推测，除非成片里直接可见或有公开资料。
- 数值带上它的来历和范围：是哪一段、量了几帧、用的什么方法。
- 不把一段里量到的数值写成这位作者的习惯，更不写成通用的规则。
- 发现先前的说法错了，在原处改掉，并注明是怎么发现的。不要只在别处追加一条相反的说法。
- 只有静帧时，只记静帧上有的东西。不从静帧推断动效、制作方式或作者意图。
- 证据不足以在两种解释之间取舍时，把两种都写下来，并写明各自需要什么证据。「判断不了」是一个可以写的结论。

## 7. 每条说法标上依据等级

同样是「观察」，可靠的程度差得很远。写的时候，带数字的说法都标上它来自哪一级：

| 等级 | 是什么 | 可以用来说什么 | 不能用来说什么 |
|---|---|---|---|
| 逐帧确认 | 步长为 1 的条带，或逐帧的数值（帧间差、相机、局部事件、主色） | 帧数、间隔、先后顺序、哪一帧 | 作者为什么这样安排 |
| 全片统计 | 对全片或一段做的统计：相位集中度、提升倍数、相关系数、面积占比 | 倾向和强弱 | 某一处具体发生了什么 |
| 隔帧或单帧 | 通览、关键帧、每 2—4 帧取一帧的条带、切点前后四帧 | 有这件事；是这个样子 | 几帧、多快、多久一次 |
| 静帧 | 海报、截图、作者发的预览图 | 层级、字号、颜色、元素之间的位置关系 | 任何关于运动的事；它是不是成片里的一帧（要配准） |
| 间接 | 从别的东西推出来的：复刻工程里的图层入点、画面里写的数字、别人的说明 | 只能当线索 | 结论 |

用法：

- 在笔记里，带帧数的说法后面写上帧号。有帧号就是逐帧看过的，没有帧号的读者会知道它是隔帧或单帧看的。
- 引用一条带数字的说法之前，先看它是哪一级。第三轮改掉的 13 条，原来全是「隔帧或单帧」这一级，却写了帧数。
- 「逐帧确认」和「全片统计」互相不能替代。统计说 V05 的画面内事件落在重音上的比例是随机水平的 3.2 倍；逐帧看 0:46 那一段，才知道落在起音上的是「构图不动、加一行内容、整屏反色一帧」。反过来，一段逐帧的例子也不能代表全片。
- 逐帧看过的地方仍然只是那几处。把它写成「在这几处看到」，不写成「这位作者总是」。

## 8. 一份笔记的结构

每件作品一份，大致是：

1. 制作信息与分工的提醒；文件参数；这次实际看了多少（几张通览、几张大图、几段条带）。
2. 段落结构表：时间、画面内容、主色、节奏。
3. 单帧设计：层级、文字、画框、色彩、质感。
4. 动效与镜头：运动质感、入场、停留、退场、转场、统计数字。
5. 声画关系：速度及其可靠程度、切点对拍的锁定、重音由什么来接、运动量与音色密度的关系、段落的对应。
6. 与静帧的对应（有的话）：哪张图对哪一帧、缩放和覆盖范围、这个画面在成片里停了几帧。
7. 推测与待验证。

写完之后再做横向比较。横向比较里的每一条归纳后面注明依据的编号，并留一节专门写「素材条件和观察方法对结论的影响」。
