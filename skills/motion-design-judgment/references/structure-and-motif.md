## 1. 一条片子一个贯穿物

**看到的**

| 作品 | 贯穿物 | 它怎么变 |
|---|---|---|
| V00 | 刻度尺；镜像的片名 | 尺子横贯画面，其他元素挂在上面 |
| V01 | 贯穿画面的小字线；旋涡纹 | — |
| V04 | 花；圆角矩形（胶囊形） | 胶囊从实心变成窗口（0:02.8）；花从小图标变成占满画框的大花（2:02.9） |
| V07 | 灰白底正中的蓝天方窗 | 出现三次，一次比一次大 |
| V08 | 片名字标及其长圆形 | 从封面原样进入成片 |
| V13 | 五线谱 | 每个词坐在一段谱线上 |
| V16 | 光盘 | 特写（0:34，从背面看）、光盘隧道（0:55）、舷窗里的主角（1:28 起）、结尾的定格 |
| V17 | 相机取景器；信封和花 | — |
| V18 | 引号；锯齿折线；黑色铬圆盘 | 引号版式在结尾回归 |
| V20 | 白色十字角色 | 推进到它占满画面当转场（0:06.2） |
| V21 | 由小竖线组成的线；圆顶建筑；乐队名的字母 | 那条线在片尾走到尽头 |
| V05 | 软件界面 | — |

**可能的原因**

- 颜色、构图、镜头都在高速地换，需要一样东西让观众认出「还是这条片子」。它的作用像标志。
- 贯穿物常常就是跨切点的锚点、转场时被放大或填满画面的那样东西、首尾呼应的那样东西。一个物件承担了好几项工作。
- 素材里的贯穿物多半轮廓简单，能从一个小图标放大到满屏而不走样。

**适用与代价**

- 贯穿物要从这条片子的内容里来：曲名、歌词里的意象、音乐的性质（V13 的谱线、V16 的光盘）、制作的方式（V05 的界面）。刻度尺是 V00 的，不是通用的。
- 它需要在全片的规划阶段就定下来，否则后面每个镜头都要回头改。
- 一个就够。素材里也有两三个并存的（V18、V21），那需要更多的镜头来分别交代它们。

## 2. 一条横贯的线

**看到的**

- V00 的刻度尺、V01 的小字线、V04 横卷段的贯穿横线、V13 的谱线、V18 的折线、V21 的短竖线组成的线、平面作品 P10—P16里伸到画面边缘的水平色带。
- 它们的共同点：横贯画面，其他元素挂在它上面或沿着它出现。

**可能的原因**

- 一条线给了散落的元素一个基准。逐个弹出的东西沿着线排开，就有了顺序和方向，读起来是「一串」，不是「一堆」。
- 相机沿着它走时，它是轨道。已有的 rollback 复刻就是靠刻度尺逐帧量出相机的位置的。
- 它把画面分成上下两部分，可以做对称或镜像（V00 的上实下镜）。

**适用与代价**

- 适用于有横向展开的内容：时间线、列举、长卷。
- 线的样子要和内容有关。直接搬刻度尺会让作品看起来像 V00 的仿作。
- 线一直在正中，构图会很对称、很平。素材里靠线上的东西疏密不均来打破。

## 3. 首尾呼应

**看到的**

- V04：标题卡回归并虚化。V18：引号版式回归。V21：那条线延伸到尽头。V20：回到黑底窄画幅。V23：发光的小圆环。V16：光盘定格，这个画面和封面 P03 几乎是同一个构图。V25：片名横带。V34：片名字标。

**可能的原因**

- 开头的东西再出现一次，观众就知道结束了，不需要字幕来说。
- 回归的时候常常变了样（虚化、定格、走到尽头），表示「经过了这一切之后」。

**适用与代价**

- 开头要留下一个足够好认的画面。
- 呼应的是贯穿物或标题版式时最省事，因为它们本来就一直在。

## 4. 同一个版式做几个版本

**看到的**

- V27：线稿版、上色版、反相版。主版式就是平面作品 P31。
- V03：固定的正中方形，每个镜头换一次底色和内容。
- V00：实物和它的纯色剪影。
- V23：同一个场景的暗版和亮版。
- V10：同一套信息角标配九种视觉。
- P21—P23、P28、P30：同一设计的三种画幅。
- P19、P25：实体专辑的封面、封底、光盘共用一套小图形。

**可能的原因**

- 一个版式的几个版本之间可以直接切换，这是成本很低的事件来源（见 [color-and-texture.md](color-and-texture.md) 第 5 节）。
- 版本之间身份不变，所以切换不会让观众迷路。
- 对制作来说，它把设计量集中在一个版式上，把它做透，而不是做很多个浅的。

**适用与代价**

- 主版式要在设计时就按「能出几个版本」来检验：去掉颜色还成立吗？反相还成立吗？只留轮廓还成立吗？
- V27 全片基本只有一个版式，靠版本和歌词的变化撑了三分钟。这要求那个版式本身足够丰富。

## 5. 把制作过程放进画面

**看到的**

- V03：四张章节卡逐行写出叠加的顺序——图形、颜色、纹理、与现实结合；片尾翻拍的显示器上是合成软件的界面。
- V05：画面里有表达式文字、软件「未响应」的弹窗、关键帧数据文本、编曲窗口截图、时间标尺和关键帧图标。
- V11：表达式文字、二维码、旋钮和滑杆。
- V02：五张带编号的章节卡给各段演示命名；隧道的缺口里露出透明底纹样的棋盘格。
- V14 片头、V16、V25、P31、P21：屏幕上的软件界面、鼠标指针阵列、文件图标、多窗口桌面、旧式画图程序、报错弹窗。
- V00 0:27、0:28：白色圆里是一段代码编辑器的截图，蓝色面板里是一段带注释的文件清单。这两样在图片 B13、B12 上看得清，在平台成片上一个是糊的，一个掉了颜色。
- 图片 B02、B04、B05、B07、B08：报错弹窗、「:(」图标、表达式文字、控制点方框和图片占位框、软件字符面板和聊天界面的截图。B08 的画面里还写着用哪个软件、哪一年做的。
- 透明底纹样的棋盘格出现在 V00、V02、V03、V05、V11、V16 和 B02—B04（见 [color-and-texture.md](color-and-texture.md) 第 9 节）。

**可能的原因**

- 这些作品有一部分是在讲「制作」本身：V03 的章节卡是一套做法的演示，V02 是分段的演示，V11 和 V25 是作品集。界面是内容的一部分。
- 它也是一种口吻：不假装画面是凭空出现的。

**可以确定的和不能确定的**

- 可以确定：V05 的作者把合成软件的弹窗和表达式文字当成了素材；V03 的作品在图层式的时间线里制作。
- 不能确定：其他作品用什么软件，表达式加在哪些图层上。V05 画面里写着每秒更新 10 次的表达式，实测的步进周期却是 6 帧和 4 帧。**画面里出现的制作信息是设计元素，不是制作记录。**
- 图片也一样。B08 画面里写的软件名和年份、B14 的视口截图、B13 里的代码，说明的是那张图里有这些东西。成片的各个部分用什么做、由谁做，仍然看不出来。
- 棋盘格是专门放的一层还是别的途径带进来的，在它固定在屏幕上的那几处判断不了。

**适用与代价**

- 适用于作品集、演示、和制作文化有关的活动宣传。
- 放在抒情的歌曲 MV 里会出戏。素材里的插画歌词类都没有这样做。

## 6. 封面与成片

**看到的**

| 平面 | 视频 | 关系 |
|---|---|---|
| P01 | V07 | 同一张插画、同类细线图解；封面的大号衬线标题不在正片里 |
| P02 | V08 | 字标原样进入成片并成为母题 |
| P03 | V16 | 与成片结尾的定格画面几乎是同一个构图；封面的元素在片中被拆开重组 |
| P04 | V18 | 方块塔、字母泡、引号、三角图标、粉蓝灰配色一致 |
| P31 | V27 | 成片的主版式就是这张图，另做了线稿版和反相版 |
| V10 片中的专辑封面 | V10 | 封面只以小方图出现在片头和片尾，没有被拆开或做动画；影像各段另选主色和字体 |

- 两个方向都有：封面的字标进入成片，成片的一帧成为封面。先后顺序没有资料。
- 平台封面上的标题普遍比成片里的大。歌词类 MV 的平台封面突出插画，动态设计类突出图形和字。
- 作者发的预览图是第三种关系。图片 B12、B13 的帖文比 V00 公开早两到三周，画面与成片的第 691、652 帧一致；B05—B07 对应 V05 的三处。这五个画面在成片里只停 1—9 帧，都是所在镜头里最完整的那一刻（见 [stills-and-motion.md](stills-and-motion.md)）。

**可能的原因**

- 封面和成片共用一套元素时，一份设计量有了两个出口，观众在两个地方认得出是同一个作品。
- 成片里一闪而过的整版被单独发出来，等于给它补了被看的时间。这是推断；这些图是在什么环节、出于什么考虑发的，没有资料。
- V10 是另一种情况：封面是别人的作品，影像不去动它，只给它留出位置，自己另起一套视觉。这是对分工的尊重，也是避免两套语言打架。

**适用与代价**

- 自己同时做封面和影像时，先把字标或主图形定下来，让它能进成片。
- 封面是别人做的时候，不要拆它、改它、给它做动画，除非对方同意。

## 7. 先问每个元素在做什么工作

前面几份文件里反复出现的那些东西——刻度尺、舷窗、括号、角标、镜像字、方块溶解——很容易被当成一套风格的配件。把它们原样拼在一起，得到的是仿作。

素材里可以带走的是**工作**，不是配件。同一项工作在不同的作品里由不同的东西承担：

| 工作 | 它解决的问题 | 素材里承担它的东西 |
|---|---|---|
| 锚点 | 快切时眼睛不用重新找位置 | 正中的圆、X 形、风车图标；歌词层；白色的二维标记 |
| 框 | 高频的内容不散；分出看的地方和质感的地方 | 椭圆舷窗、引号、章节卡、三条竖向分区、宽银幕黑边 |
| 轴 | 逐个出现的元素有顺序和方向 | 刻度尺、谱线、小字线、折线、水平色带 |
| 页眉页脚 | 画面有系统的口吻；跨镜头的身份 | 曲目信息角标、四角字幕、底边信息栏 |
| 纹理 | 大面积的空不显得没做完 | 小字线、贴在地面上的字段名、重复的标签和胶带 |
| 标注 | 不同来历的东西并置在一张图里 | 引线、细线方框、坐标读数、色样 |
| 事件 | 在一帧内接住重音 | 原地换形、变粗、换色、边缘弹出、换底、一个调色板以外的颜色 |
| 段落标记 | 观众知道换了一段 | 底色、画幅、歌词的排法、整套主色 |
| 预告 | 新东西来之前先打招呼 | 剪影或二值版本、黑底上先出的歌词、提前埋在上一个镜头里的形状、提前两帧从画面边缘滑进来的下一个场景的东西 |
| 换的标记 | 原地替换不被读成抖动；「这里换了」有一个看得见的时刻 | 一帧变蓝或带碎块、一帧整屏反色、一条扫过的横条、一帧黑白二值 |
| 清空 | 观众知道一样东西被拿掉了，位置空出来了 | 棋盘格填充、插在两件东西之间的一帧空白、逐字母退掉的词 |
| 呼吸 | 强的地方显得强 | 音乐停时的静止画面、黑场、留白的章节卡 |
| 暂停时的内容 | 画面经得起截图和重看 | 整版的小字和小件、界面截图里的代码和文件清单、词条下面的释义 |
| 贯穿物 | 全片是一条 | 光盘、蓝天方窗、字标、十字角色 |

用法：

1. 拿到一个需求，先列出它需要哪几项工作。不是每一项都需要。
2. 每一项工作，从**这条片子自己的内容**里找一样东西来承担。曲名、歌词的意象、音乐的性质、发布的场合、已有的插画或标志，都是来源。
3. 一样东西能承担的工作越多越好（贯穿物兼做锚点和首尾呼应）。
4. 想用素材里的某个具体元素时，先说出它在原作里做的是哪项工作，再问自己的片子里有没有这项工作要做，以及是不是有更贴内容的东西可以做。

## 8. 在自己的稿子上怎么查

| 想确认的事 | 做法 |
|---|---|
| 有没有贯穿物 | `vis.py sheet` 出一张全片通览。指出每一段里它在哪儿；指不出来的段落要有理由 |
| 开头和结尾是否呼应 | 把第一个完整画面和最后一个完整画面并排看 |
| 主版式能出几个版本 | 做出去色、反相、只留轮廓三版，看哪一版不成立 |
| 每个元素是否有工作 | 对着第 7 节的表逐个问。说不出工作的元素先拿掉，看画面有没有变差 |
| 是否成了某件作品的仿作 | 把稿子里的元素清单和单独一件素材的元素清单比一下。重合的是「工作」没问题，重合的是一整组具体的配件就要改 |
