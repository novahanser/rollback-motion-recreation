## AE 工程

下载并完整解压 `collected_v12.zip`，在 After Effects 中打开其中的 `rollback_replica_v12.aep`。请保留压缩包内的目录结构；如果在其他电脑上打开时提示缺失素材，可根据提示重新定位到解压后的 `(Footage)` 文件夹。

根据压缩包内的收集报告：

- 工程使用 After Effects 2024，主合成 `RB_MAIN` 为 1920 × 1080、24 fps，时长约 11.33 秒。
- 收集了 516 个素材文件；报告记录收集时缺失素材为 0，使用 AE 自带效果，没有第三方插件或字体依赖。
- 压缩包不包含原片、最终成片、素材重绘的原始生成结果、生成脚本及旧版未使用素材。

以上是原收集报告记录的情况；不同设备打开时请自行检查素材与效果。收集报告和重建 JSON 中包含收集时的本地路径，公开分享前请检查。

## Skill 是什么

[SKILL.md](SKILL.md) 是一份给 AI 助手使用的方法文档，名称为 `longscroll-collage-motion`。它总结了长卷拼贴类平面动效的视觉和运动语言，并记录如何分析参考片、搭建 AE 工程和检查复刻结果。主要内容包括：

1. **画面设计**：横向长卷、居中刻度尺、限色拼贴、镜像与剪影等版式和视觉元素。
2. **运动节奏**：相机平移与缩放、按拍跳变、剪影占位、擦除和闪帧等做法。
3. **复刻分析**：抽帧、测量相机、还原世界坐标、逐元素对比和迭代。
4. **工程与交付**：AE 工程结构、脚本化搭建思路、收集素材、渲染和核对。

### 如何使用

把 `SKILL.md` 交给支持 Skill 文件的 AI 助手，按所用工具的说明导入，或在任务中直接附上文件。可以从类似下面的需求开始：

> 参考这份 Skill，帮我拆解一段长卷拼贴动效，列出镜头、节奏、素材与 AE 搭建步骤。

Skill 是方法说明，并不是一键运行的程序。文中提到的 `rollback-replica/` 参考实现、`scripts/`、测量工具及 After Effects MCP 能力均需另行准备，本仓库没有提供这些脚本或服务；所附压缩包提供的是已收集的 AE 工程。
